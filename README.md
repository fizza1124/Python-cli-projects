# 🐍 Python CLI Projects

A collection of beginner-friendly Python projects built to practice programming fundamentals, improve problem-solving skills, and gain hands-on experience with Python.

## 📂 Projects

### 1. 🧮 Simple Calculator

A command-line calculator that performs basic arithmetic operations.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division

**Concepts Used:**
- Variables and data types
- User input
- Conditional statements
- Arithmetic operators

**How to Run:**

```bash
python calculator.py
```

### 2. 📝 To-Do List CLI App

A command-line application that helps users manage their daily tasks.

**Features:**
- Add new tasks
- View existing tasks
- Delete tasks
- Interactive menu

**Concepts Used:**
- Lists
- Functions
- Loops
- Conditional statements
- Exception handling

**How to Run:**

```bash
python "to-do list.py"
```

**Note:** Tasks are stored in memory and disappear when the program exits.

### 3. 🎯 Number Guessing Game

A command-line game in which the player tries to guess a randomly generated number.

**Features:**
- Random number generation
- User guesses
- Feedback on guesses
- Repeated attempts until the correct number is guessed

**Concepts Used:**
- Variables
- User input
- Loops
- Conditional statements
- Python `random` module

**How to Run:**

```bash
python number_guessing.py
```

## 🛠️ Requirements

- Python 3.x
- A terminal or command prompt
- A Python-compatible environment

## 🚀 Getting Started

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open a terminal in the repository folder.
4. Run the Python file for the project you want to use.

These projects help develop skills in:
