#  Simple Calculator

A beginner-friendly calculator built with Python that performs basic arithmetic operations through a command-line interface.

# Features

- Addition
- Subtraction
- Multiplication
- Division
- User input for numbers and operations

# Technologies Used

- Python 3

# Concepts Learned

- Variables and data types
- User input
- Conditional statements
- Arithmetic operators
- Basic error handling

## 🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run 

# Purpose

This project was created to practice Python fundamentals and understand how to build a simple interactive program.
